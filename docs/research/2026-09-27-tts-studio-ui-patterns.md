# TTS studio UI patterns: how the best TTS products design the "type text, hear speech" screen

**Date:** 2026-09-27
**Question:** How do the best text-to-speech products lay out their main TTS screen (text, voice, settings, generate/playback, history, long-form, editing, shortcuts)? Which of those patterns fit a redesign of Tesseract's Speech page, given an offline, instruction-driven engine (Qwen3-TTS 1.7B VoiceDesign on MLX, a **Pinned Voice** with a **Reference Take**, streaming segments, per-token character offsets, fn+Space and the notch overlay)?

**Method.** Primary sources only: product docs and help centers, official blogs and changelogs, and one open-source product (OpenAI.fm). All were read on 2026-09-27. Docs screenshots were viewed where noted. Product UIs change faster than their docs, so treat layout details as "as documented".
**Not reachable:** the Google AI Studio and Hume Platform UIs need a sign-in, so their UI details come from docs and blog posts. openai.com returned 403, so the date comes from search results. WellSaid's help pages returned 403 as HTML, so they were read through the Zendesk JSON API. Voice Dream's help pages return 404.

---

## 1. ElevenLabs

### Text to Speech page
- **Layout** (per the guide's screenshot): a large plain-text canvas on the left and a right panel with **Settings | History** tabs. Settings stacks **Voice** (avatar, name, chevron), **Model** (badge such as "V2", name, chevron), the sliders, a **Speaker boost** toggle and **Reset values**. The canvas footer holds "N credits remaining", a "235 / 5,000 characters" counter, a download icon and a black **Generate speech** button. — [TTS guide](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech)
- The flow is 4 steps: type/paste, pick a voice, optionally adjust settings, click Generate. The docs rank influence as **Voice > Model > Settings**. — [TTS guide](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech)
- **Models** show limits in the picker: Eleven v3 (5,000 chars, 70+ languages, dialogue), v3 Conversational (~280 ms), Multilingual v2 (10,000 chars, "most stable on long-form"), Flash v2.5 (40,000 chars, ~75 ms). — [TTS guide](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech)
- **Language is not selectable on the website.** It is auto-detected from the text, and the voice decides the accent. The API accepts `language_code`. Text normalization of numbers, dates and symbols is on by default in the UI. — [TTS guide FAQ](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech)

### Voice settings (names, end labels, defaults, ranges)
- **Speed**: "Slower ↔ Faster", default 1.0, range 0.7–1.2. **Stability**: "More variable ↔ More stable", default 0.5. **Similarity**: "Low ↔ High", default 0.75. **Style Exaggeration**: "None ↔ Exaggerated", default 0, and the docs say "keep this setting at 0 at all times". **Speaker boost**: toggle, default on. The docs present these as ranges of randomness rather than exact controls: "setting the sliders to specific values won't guarantee the same results." — [TTS guide](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech), [default settings API](https://elevenlabs.io/docs/api-reference/voices/settings/get-default)
- **Eleven v3 collapses the panel.** Stability becomes a 3-stop control, **Creative / Natural / Robust**, with slider ends labeled "Creative ↔ Robust". Similarity, Speed and Speaker Boost are listed as unavailable for v3, where speed is steered with audio tags. — [v3 prompting](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices#prompting-eleven-v3)
- **Seed is API-only.** It is "best effort" deterministic and is not in the documented UI. The API also takes `previous_text`, `next_text` and `previous_request_ids` so chunked long text keeps its prosody ("request stitching"; not available for v3). — [convert API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [stitching](https://elevenlabs.io/docs/eleven-api/guides/how-to/text-to-speech/request-stitching)

### Generate, regenerate, history
- **Free regenerations.** The button reads **Regenerate speech** twice for free when the text, voice and model are unchanged (sliders may change), the first generation is under 2 h old and the page hasn't been refreshed. Hovering shows the remaining count. Afterwards it returns to **Generate speech** and shows the credit cost. — [help](https://elevenlabs.io/docs/help-center/product/core-capabilities/text-to-speech/is-there-a-way-to-preview-audio-without-losing-quota-before-downloading)
- **History tab** (right panel; on narrow screens a history icon above Generate speech). Each item has a download icon with MP3 128 kbps or WAV. **Advanced** adds MP3 192/256, M4A and FLAC. — [help](https://elevenlabs.io/docs/help-center/product/core-capabilities/text-to-speech/how-do-i-download-wav-m4a-and-flac-files)
- A history item stores the text, voice id/name/category, model, settings, date, source (TTS, Projects, …), output format and **alignments** (per-character start/end times). A bulk download returns a single file or a .zip. — [history item API](https://elevenlabs.io/docs/api-reference/history/get), [download API](https://elevenlabs.io/docs/api-reference/history/download)

### v3 audio tags and the Enhance button
- **Inline square-bracket tags** in the script: emotions (`[sad]`, `[curious]`, `[excited]`), delivery (`[whispers]`, `[shouts]`), reactions (`[laughs]`, `[sighs]`, `[clears throat]`), SFX (`[applause]`) and `[strong X accent]`. Ellipses add pauses and CAPS add emphasis. v3 ignores SSML `<break>`; v2/Flash accept `<break time="1.5s" />` up to 3 s. — [v3 prompting](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices#prompting-eleven-v3), [TTS guide FAQ](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech)
- **Enhance** "automatically generate[s] relevant audio tags for your input text". It is an LLM pass whose system prompt ElevenLabs publishes. The key rule is "DO NOT alter, add, or remove any words". It may only add tags, CAPS, "?", "!" and ellipses. — [Enhancing input](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)

### Studio (long-form; now "ElevenCreative Studio 4.0")
- **Structure:** a Chapters sidebar (auto-detected on import), paragraphs, and a contextual sidebar with **Playback controls, Type, Model, Voice, Override settings, Generation history**. Its **AI Tools** are Enhance text, Remove background audio, Use voice changer, and "Direct speech with your voice" (Actor Mode). A multi-track timeline sits at the bottom with trim, split, duplicate and zoom, adjustable timing between paragraphs or sentences, and waveforms. — [Studio](https://elevenlabs.io/docs/eleven-creative/products/studio)
- **Status and regeneration:** a pale grey bar left of an unconverted paragraph turns dark grey once generated. Editing the text or voice clears the status. You can regenerate a whole paragraph, or select words and "regenerate only those words", with a whole phrase or sentence recommended. Per-paragraph **Generation history** lets you play and download each take, **Restore generation**, or delete one (permanently). **Lock paragraph** protects narration. — [Studio](https://elevenlabs.io/docs/eleven-creative/products/studio)
- The **Play button has three modes**: "Until end (generate clips ahead)", "Until end (generate one at a time)" and "Selection". It plays existing audio and generates missing paragraphs. — [Studio](https://elevenlabs.io/docs/eleven-creative/products/studio)
- **Other controls:** per-selection voices shown as colored orbs (Cmd+Opt+A shows every orb), **Override settings** for selected text, a per-project voice **Alias**, Volume −30 to +5 dB, **Insert break** (default 1 s, max 3 s), a Pronunciations editor (alias/phoneme rules), and **Project options > Keyboard shortcuts**. Export runs automatic QA ("volume distortions, voice similarity, mispronunciations, missing or additional words") and regenerates up to twice. — [Studio](https://elevenlabs.io/docs/eleven-creative/products/studio)

### Voice Design, Library, Remix
- **Voice Design modal** (screenshot): **Prompt** with a **Randomize** button, **Text to preview** with an **Auto-generate** button and a "174/1,000" counter, and **Generate voice**. It returns **three** previews for one charge, and you save one into a voice slot. The recommended prompt format is "Native <Language>. <Gender>, <Age range>. <Quality level>. Persona: … Emotion: …" plus 1–2 sentences on timbre and pacing. — [Voice Design](https://elevenlabs.io/docs/eleven-creative/voices/voice-design)
- **Preview-text guidance:** the preview text "should complement the voice description, not contradict it", and "longer preview texts tend to produce more stable and expressive results". Parameters are **Loudness** (default 0.5) and **Guidance Scale** (default 5, prompt adherence vs. quality). The API also has `seed`, `auto_generate_text` and `should_enhance` ("expand simple prompts into more detailed voice descriptions"). — [Voice Design](https://elevenlabs.io/docs/eleven-creative/voices/voice-design), [design API](https://elevenlabs.io/docs/api-reference/text-to-voice/design)
- **Voice Library:** search by name, keyword, ID or a dropped audio file. Sort by Trending, Latest, Most users or Character usage. Filter by language, then accent, category, gender, age, notice period, Live Moderation and quality. There are Handpicked Collections, a preview "orb", **+** to save, and **T** to open TTS with that voice. — [Voice Library](https://elevenlabs.io/docs/eleven-creative/voices/voice-library), [quickstart](https://elevenlabs.io/docs/eleven-creative/quickstart)
- **Voice Remixing** changes a voice with a natural-language prompt at Low/Medium/High/Max prompt strength. It "creates a new voice variant — the original voice is not modified", and variants can be remixed again without limit. — [Remixing](https://elevenlabs.io/docs/overview/capabilities/voice-remixing)

## 2. OpenAI.fm (gpt-4o-mini-tts demo; source read on GitHub)
- **One screen with three blocks and a footer:** **VOICE** is a row of 11 keycap-style voice buttons, each with an LED dot, a star on the "expressive" voices (ash, ballad, coral, sage, verse) and a **shuffle** key. **VIBE** is 5 random preset cards plus a refresh key, above an editable instructions textarea. **SCRIPT** is a textarea with a live character count. The footer has **DOWNLOAD | SHARE | PLAY**. — [TTSPage.tsx](https://github.com/openai/openai-fm/blob/main/src/components/TTSPage.tsx), [Footer.tsx](https://github.com/openai/openai-fm/blob/main/src/components/ui/Footer.tsx), [screenshot](https://github.com/openai/openai-fm/blob/main/public/screenshot.jpg)
- **There are no sliders.** The Vibe text is sent as `instructions`, and the page steers only through voice, instructions and script, each capped at 1,000 chars. — [generate route](https://github.com/openai/openai-fm/blob/main/src/app/api/generate/route.ts)
- **Vibes are structured prose presets** (Calm, Dramatic, Serene, Bedtime Story, …). Each has labeled lines such as "Voice Affect:", "Tone:", "Pacing:", "Emotion:", "Pronunciation:", "Pauses:" and a matching sample script. — [library.ts](https://github.com/openai/openai-fm/blob/main/src/lib/library.ts)
- **Clever state rules.** Picking a vibe replaces the script only if the user hasn't edited it; an edited script shows a **Reset** link. Editing the vibe text deselects the preset card. Any change clears the last audio URL. — [TTSPage.tsx](https://github.com/openai/openai-fm/blob/main/src/components/TTSPage.tsx)
- **Play = generate.** The button goes **Play → Busy → Stop**, the audio streams from the API as it arrives, and 5 live amplitude bars (WebAudio analyser) replace the icon. — [PlayButton.tsx](https://github.com/openai/openai-fm/blob/main/src/components/PlayButton.tsx)
- **Share** saves only the recipe {input, prompt, voice} and restores it from a URL hash. A `</>` dev-mode toggle swaps the board for Python, JavaScript and cURL snippets. — [share route](https://github.com/openai/openai-fm/blob/main/src/app/api/share/route.ts)
- The API guide lists what instructions can control: accent, emotional range, intonation, impressions, speed, tone, whispering. It now lists 13 voices and recommends `marin` and `cedar`, which the demo lacks, so the demo lags the API. The model launched in March 2025 ("instruct the model not just on what to say but how to say it"; the post returned 403, so this comes from search results). — [TTS guide](https://developers.openai.com/api/docs/guides/text-to-speech), [announcement](https://openai.com/index/introducing-our-next-generation-audio-models/)

## 3. Hume Octave
- **Voice Design UI:** write a description and optionally toggle **Enhance description** to have it rewritten. Pick a model and an optional custom script, then **Generate samples** makes **three candidates**. Preview each, then name the voice, tag it (language, accent, gender, age) and **Save** to the Voice Library. The docs say a saved voice "stores both the speech and the prompt that shaped it, so the model can reliably reproduce the same vocal identity". — [Voice Design](https://dev.hume.ai/docs/voice/voice-design)
- **The `description` field has two roles.** Without a voice it is a *voice prompt* that creates a voice. With a voice it is *acting directions*, which Hume says to keep to "100 characters or fewer". — [API](https://dev.hume.ai/reference/text-to-speech-tts/synthesize-json)
- **Acting instructions** tips: keep them short ("frightened, rushed"), use precise emotions, combine emotion with delivery, name the audience, and use the `speed` parameter (0.5–2.0, non-linear) rather than words for rate. `trailing_silence` and inline `[pause]` / `[long pause]` handle pauses. — [Acting instructions](https://dev.hume.ai/docs/text-to-speech-tts/acting-instructions)
- **Continuation:** chained utterances continue from the previous one, and `context` (a prior `generation_id` or context utterances) carries delivery across requests. Context also resolves homographs ("bow", "bass", "read"). `num_generations` produces variants that share prosodic context. — [Continuation](https://dev.hume.ai/docs/text-to-speech-tts/continuation), [API](https://dev.hume.ai/reference/text-to-speech-tts/synthesize-json)
- **Octave 2** returns word and phoneme timestamps "for real-time captions or word highlighting". Instant (low-latency) mode is on by default but must be off for voice design and multi-candidate requests. As of today the docs say voice design requires Octave 1. — [Timestamps](https://dev.hume.ai/docs/text-to-speech-tts/timestamps), [Overview](https://dev.hume.ai/docs/text-to-speech-tts/overview)
- **Launch posts:** in the playground you can "click Generate without selecting a voice" and a voice is invented from the script (Feb 26, 2025). **Creator Studio** imports PDF, EPUB, Word or text, detects chapters and dialogue, lets you tag lines by character with per-line direction, and exports chapter-separated files with metadata. Octave 2 (Oct 1, 2025) added 11 languages and phoneme editing. — [Octave post](https://www.hume.ai/blog/octave-the-first-text-to-speech-model-that-understands-what-its-saying), [Creator Studio](https://www.hume.ai/creator-studio), [Octave 2](https://www.hume.ai/blog/octave-2-launch)

## 4. Descript (text-based audio editing)
- **The script is the media.** Deleting text deletes the audio, and cut/paste moves it. Edits are non-destructive: right-click an edit boundary and choose **Restore removed media**. **Ignore** strikes text through and mutes it while keeping it visible. **Remove from transcript** hides text but keeps the audio. The **wordbar** under the script editor adjusts word boundaries and gaps. Bulk tools cover filler words and **Shorten word gaps**. — [Edit like a doc](https://help.descript.com/getting-started/edit-like-a-doc), [terms](https://help.descript.com/descript-terms-and-concepts)
- **Regenerate:** select text, click Regenerate in the selection toolbar or **press D**, type the new words, then Regenerate. It needs a custom AI speaker, works in English only and takes up to 250 chars per action. A separate Regenerate workflow smooths "jumpy, abrupt, or awkward" edits without changing the words. — [Regenerate](https://help.descript.com/script-editing/change-meaning)
- **TTS in the script:** **Add speaker**, then **Write mode**, then **Done writing** generates the audio. For multiple voices, select text and press **@** to assign a speaker. **Tone tags** come from a **Tone** button (wave icon) with presets (serious, sigh, laugh, long pause) or Custom (≤150 chars). They render as gray text in parentheses, and their scope is the paragraph. Descript's own caveat for ElevenLabs v3/v4 is possible "shifts in tone, volume, accent, or even speaker identity" across paragraphs. TTS clips must be **Convert[ed] to audio** before timeline edits. — [Generate TTS](https://help.descript.com/ai-speech/tts)

## 5. Speechify (reader UX; Mac help center)
- **Play Selected Text:** select text in any app and press **⌥A**. A **Miniplayer** appears and playback starts. **⌥Q** plays/pauses and the Miniplayer's **x** cancels. The Miniplayer is "a small floating bar… on top of all your other windows"; you can move it, keep it visible or minimize it. — [Play selected](https://help.speechify.com/en/articles/15097404-how-to-use-play-selected-text-on-mac), [Miniplayer](https://help.speechify.com/en/articles/15097417-what-is-the-miniplayer-on-mac)
- **Display modes:** **Show Miniplayer / Show Subtitles / Hide Miniplayer**. Subtitles "display the text being read" in real time, and changes apply immediately. — [Subtitles](https://help.speechify.com/en/articles/8808123-how-to-enable-and-disable-subtitles-on-the-speechify-mac-app), [Miniplayer settings](https://help.speechify.com/en/articles/15097421-how-to-change-miniplayer-and-subtitles-settings-on-mac)
- **Speed:** a dropdown in the app window, the menu bar and the Miniplayer's ⋯ menu. **⌥D / ⌥S** change speed by ±0.05×. **Increase Speed Automatically** raises it "after every 900 words". The range is 0.5×–4.5× (100–900 wpm). — [Voice & speed](https://help.speechify.com/en/articles/15097410-how-to-change-voice-and-speed-on-the-mac-app), [auto speed](https://help.speechify.com/en/articles/8808202-how-to-increase-the-reading-speed-on-the-mac-app), [Mac guide blog, 2025-03-12](https://speechify.com/blog/ultimate-guide-to-the-speechify-mac-app-for-text-to-speech/)
- **Structure:** a menu-bar app ("so your shortcuts are always available") with a dashboard of Home, Dictation, **Text to Speech** (voice, speed, shortcuts, Miniplayer settings) and **Shortcuts** (all remappable). Listening history has a **Clear All**. Voices are either **on-device** (offline, instant, "may be less expressive") or **cloud**. The Fall 2024 redesign added a voice/speed picker with integrated search ([news, 2024-11-19](https://speechify.com/news/speechify-mac-app-fall/)). — [Getting to know](https://help.speechify.com/en/articles/8715689-getting-to-know-the-speechify-mac-app), [history](https://help.speechify.com/en/articles/16196964-how-to-delete-text-to-speech-history-using-macapp), [on-device vs cloud](https://help.speechify.com/en/articles/15097416-what-is-the-difference-between-on-device-and-cloud-voices-on-mac)
- **Web/extension reading:** skip forward/back by one sentence; a **Click to Jump** toggle to start from any sentence; **Auto Scroll** and **Text Highlighting** toggles; and **Auto Skip content** for headers, footers, footnotes, tables, citations, URLs and bracketed text, in Classic or AI Enhanced mode. — [skip](https://help.speechify.com/en/articles/7980119-how-can-i-skip-forward-and-backward-within-my-document-on-the-computer), [click to jump](https://help.speechify.com/en/articles/15039232-how-to-move-between-sentences-click-to-jump), [auto-scroll](https://help.speechify.com/en/articles/15146946-how-to-turn-auto-scrolling-on-and-off), [auto skip](https://help.speechify.com/en/articles/7973999-how-to-skip-content-such-as-headers-footers-brackets-etc-on-the-computer)

## 6. Google AI Studio "Generate speech" (Gemini TTS)
- **Gemini 3.8 TTS (post dated 2026-09-23):** AI Studio is now "a voice design workspace" where you can prompt a new voice or replicate your own, then use a "dual-speaker screenplay editor to direct line-by-line delivery". Inline cues look like `<laughs>` and `<sigh>`, and listener interjections look like `|mhm|`. — [3.8 post](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/)
- **The text is a verbatim transcript.** Sustained delivery goes in a per-turn `style` field ("whispered urgently"). Moments go inline in angle brackets (`<short pause>`, `<long pause>`, `<cough>`). CAPS add emphasis and `|…|` adds backchannels. Single-request multi-speaker supports up to 2 prebuilt voices. — [TTS guide](https://ai.google.dev/gemini-api/docs/speech-generation)
- **Guidance on identity versus delivery.** Long "Audio Profile" and "Director's Notes" blocks "are the most common cause of voice drift". Design the persona once in Voice design. Don't add "hold the voice steady" instructions, because "extra prompt text increases drift". Test with an empty `style` first. Permanent traits (age, gender, accent) belong in the voice, not in `style`. — [TTS guide](https://ai.google.dev/gemini-api/docs/speech-generation), [Voice design](https://ai.google.dev/gemini-api/docs/voice-design)
- **This reverses Google's advice from April 2026.** The 3.1 launch encouraged "Audio Profiles" and "Director's Notes" and could export the exact parameters as API code. — [3.1 post](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-1-flash-tts/)
- **Voice design API:** a 1–2 sentence description returns a persistent voice ID plus a WAV `sample_audio`, with 200 voices per project and a 1-year TTL. The 30 prebuilt voices are listed as name plus one-word character (Zephyr: Bright, Kore: Firm, Enceladus: Breathy, Sulafat: Warm, …). Library filters are language, accent, gender, pitch, persona, context and free-text search. — [Voice design](https://ai.google.dev/gemini-api/docs/voice-design), [TTS guide](https://ai.google.dev/gemini-api/docs/speech-generation)

## 7. Cartesia Sonic (playground and API)
- **Speed, volume and emotion** can be set in the play.cartesia.ai UI, per request, or with inline SSML-like tags. Speed runs 0.6–1.5 and volume 0.5–2.0, both default 1.0, and are treated as "guidance, not a strict multiplier". Emotion is in beta, English only, with a fixed list whose primary emotions are neutral, calm, angry, content, sad and scared. Other tags are `[laughter]`, `<break time="1s"/>` and `<spell>ABC123</spell>`. Break tags "split the generation", so speech sounds less natural. — [controls](https://docs.cartesia.ai/build-with-cartesia/capability-guides/volume-speed-emotion), [SSML tags](https://docs.cartesia.ai/build-with-cartesia/capability-guides/ssml-tags)
- **The direction of travel is fewer knobs.** Sonic 3.5 (Apr 2026) temporarily disabled speed and volume on `-latest`: "you may find that you don't need to use speed control as much". The docs call the controls "a refinement for specific cases rather than a default". The playground keeps a TTS History with a source column (api/playground). — [changelog 2026](https://docs.cartesia.ai/changelog/2026), [changelog 2025](https://docs.cartesia.ai/changelog/2025)

## 8. Murf Studio (block-based script)
- **Blocks and sub-blocks:** a block is a paragraph and each sub-block a sentence, and every block also appears on the bottom timeline. Pasted text brings up **Paste Preferences** ("Split Script by Paragraphs / Sentences / Don't Split"). Play buttons appear at sub-block, block and project level and render on click; an empty button "will turn black" when ready. — [blocks](https://help.murf.ai/working-with-a-block), [first voiceover](https://help.murf.ai/creating-your-first-voice-over)
- **Per-block settings:** voice, style, **Speed** and **Pitch** (−50% to +50%). The block menu has Copy/Paste Block Settings, **Apply Settings to Project**, and Download Audio/Script per block. **Emphasis** is a per-word speed/pitch graph. **Variability** 0–5 gives more varied takes and "multiple outputs for the same sentence". **Say it My Way** mimics a recorded read. — [speed & pitch](https://help.murf.ai/basic-settings-speed-and-pitch), [variability](https://help.murf.ai/variability), [Say it My Way](https://help.murf.ai/say-it-my-way)
- **Pauses:** presets are Extra Weak 0.25 s, Weak 0.5, Medium 0.75, Strong 1, Extra Strong 1.25, or Custom 0.1–5 s, inserted at the cursor. The typed form `[pause 2s]` is highlighted purple, and typing `[` opens a picker. — [pause](https://help.murf.ai/pause)
- **Shortcuts:** Enter splits into sub-blocks, ⌘Enter splits into blocks, Backspace×2 merges, ←/→ moves between blocks and ⌘←/→ reorders them. — [shortcuts](https://help.murf.ai/keyboard-shortcuts)

## 9. WellSaid Studio (sections, takes, cues)
- **Flow:** the Voices library opens on a new project. Voice cards have a play icon, a **Style** dropdown (style and model), **Use voice** and a heart for **Favorites**. Importing a script splits it by paragraphs, by sentences, or not at all. — [Getting started](https://help.wellsaid.io/hc/en-us/articles/39187892094099-Getting-Started-with-WellSaid-Studio) (updated 2026-08-07)
- **Takes:** the play icon generates the first take and the **Retake** icon (circling arrows) makes a new take from the same text. **Take [#]** opens Take history, where **Use Take** restores a take and ⋯ deletes one. Download as .mp3, .wav or .ogg, with optional caption files (.srt, .vtt, .txt). — [Getting started](https://help.wellsaid.io/hc/en-us/articles/39187892094099-Getting-Started-with-WellSaid-Studio)
- **Voice Cues:** select text and the right sidebar offers **Emotional Presets** (Happy, Excited, Calm, Stern, Serious, Secretive) or **Fine-tune** sliders for loudness, pace, pitch and pause. Cues show as colored underlines (green, yellow, purple, red; white with a tooltip when stacked). **Bulk Cues** apply across sections. Other tools are replacements, respellings and **Rewrite for Speech**. — [Voice Cues](https://help.wellsaid.io/hc/en-us/articles/39185803987347-Guide-to-Voice-Cues) (updated 2026-09-22)

## 10. Apple-native precedent (macOS 26) and Voice Dream Reader
- **Speak selection** (System Settings > Accessibility > **Read & Speak**, which was called "Spoken Content" through [macOS 15](https://support.apple.com/guide/mac-help/spch638/15.0/mac/15.0)). The default shortcut is **Option-Esc**, and pressing it again stops. With no selection it speaks the window's text items, and if there's nothing to speak "a sound plays". The **controller** can change the rate, move ±1 sentence, pause/resume and stop. — [Speak text](https://support.apple.com/guide/mac-help/mh27448/26/mac/26)
- **Highlight settings, a near-direct template for the notch:** **Highlight content**: Words / Sentences / Both / None. **Word color**. **Sentence color**. **Sentence style**: Underline / Background color. **Show controller**: Automatically / Never / Always. The same page has **Detect languages** (switch voice per language) and **Pronunciations**, a custom list. — [Read & Speak settings](https://support.apple.com/guide/mac-help/spch638/26/mac/26)
- **Accessibility Reader** (Command-Esc) opens a full-screen reading view. Settings are theme, colors, font, line/word/character spacing, readable width, and **Playback Highlighting** (Show Highlight, style, color). Controls are play/pause, skip back/forward, a speed menu and a scrub slider, plus **Autoplay**. — [Accessibility Reader](https://support.apple.com/guide/mac-help/mchl799f6fb9/26/mac/26)
- **Live Speech:** a **Type to Speak** field where Return speaks, with a voice choice that includes Personal Voice. **Saved phrases** can be grouped into categories, the window shows or hides from the menu bar, and font size is adjustable. — [Live Speech](https://support.apple.com/guide/mac-help/mchl86b6234f/26/mac/26), [settings](https://support.apple.com/guide/mac-help/mchl4876c66a/26/mac/26)
- **Voice Dream Reader Desktop** is a native Mac app whose iOS version won a 2021 Apple Design Award. It uses offline voices, highlights the spoken word, auto-scrolls, has a full-screen distraction-free mode, "Pac-Man and RSVP" speed-reading modes, user pronunciation rules, and "Save speech to audio files". The latest version is 2.0.2 (2025-05-19). — [App Store](https://apps.apple.com/us/app/voice-dream-reader-desktop/id972112040?mt=12)

## Implications for an offline, instruction-driven macOS TTS page

**Patterns that fit the engine**
1. **Canvas + inspector.** Put a large text canvas on the left and a trailing inspector (SwiftUI `.inspector`) with **Voice** and **History** tabs, following ElevenLabs' Settings | History. The footer holds the character/segment count, Export, and one primary **Speak** button that becomes **Stop** while streaming (OpenAI.fm Play → Busy → Stop). Where ElevenLabs shows credits, show engine **Readiness** (unloaded / loaded / warm), because that is what actually gates the first sound here.
2. **The voice is the description.** The description field is our equivalent of OpenAI.fm's Vibe box and ElevenLabs'/Hume's design prompt. Offer 5–8 preset "vibe" chips that write a scaffolded description plus a shuffle button. Editing the text deselects the chip, as OpenAI.fm does. Give a short scaffold (who, timbre, pace, mood). Gemini 3.8 blames long "Director's Notes" blocks for voice drift; whether that holds for Qwen3-TTS VoiceDesign needs a test before we pick a default length.
3. **Pinning is the "save voice" step.** ElevenLabs and Hume make 3 candidates, then you pick, name and save. Locally, three renders cost three times the GPU time, so use WellSaid's model instead. Each **Try another take** adds a replayable take to a small strip, and **Pin this take** + name turns the chosen take into the **Pinned Voice**. Keep the previous takes restorable ("Use Take").
4. **Treat the Reference Take text as its own input.** ElevenLabs says preview text must match the description, and that longer text is more stable. Hume pairs the prompt with "a sample line". Because our first rendered sentence becomes the Reference Take, show which sentence it was, and let the voice designer set a dedicated reference line per language, auto-written by the on-device LLM like ElevenLabs' Auto-generate.
5. **A pinned voice's identity is fixed.** Hume switches `description` from voice prompt to acting direction once a voice exists, and ElevenLabs Remix forks instead of mutating. Editing a pinned voice's description should therefore create a new voice, not silently change the pinned one.
6. **Settings: two sliders, the rest behind Advanced.** Show two sliders with plain end labels and a **Reset values** button. For example, temperature as "Steady ↔ Lively" and detail temperature as "Timbre: steady ↔ varied"; these names are suggestions. Put top-p, repetition penalty, max tokens and seed under **Advanced**, following ElevenLabs keeping seed out of the UI. Record the seed with each history item rather than asking for it up front.
7. **Speed is a playback control.** Put it in the player and notch, not the generation settings. Speechify uses 0.5–4.5× in ±0.05 steps (⌥D/⌥S); Apple's controller has a rate control. Word-highlight times must be divided by the same rate.
8. **Highlighting follows Apple's Read & Speak settings.** Offer words / sentences / both / none, word color, sentence color, and sentence style (underline or background), in both the canvas and the notch. Add a "show overlay" setting: Automatically / Always / Never (Apple), or Speechify's Miniplayer / Subtitles / Hide. Our per-token character offsets already support this, plus Speechify's **Click to Jump** and **Auto Scroll** for audio that has already been rendered.
9. **Hotkey semantics.** Pressing fn+Space again stops (Apple). Add configurable pause/resume and speed ± hotkeys (Speechify ⌥Q, ⌥D/⌥S). With nothing selected, give feedback (a sound or a brief notch message, as Apple does) rather than failing silently. List every shortcut in one place, like Speechify's Shortcuts tab.
10. **History is a local library with no quota semantics.** Each record holds the text, a Pinned Voice reference (description + take fingerprint), settings, seed, date and word timings; ElevenLabs stores the same fields, including alignments. Actions are replay with highlighting, Export WAV/M4A, captions (.srt/.vtt) from the timings as WellSaid does, **Open in editor** (restore text and settings), delete, and **Clear All** (Speechify). MP3 would need a bundled encoder, since macOS doesn't ship one.
11. **Long text.** Show segment status bars (Studio's pale grey → dark grey), per-segment **Retake** with take history, and **Lock** for good segments. Studio's three Play modes (generate ahead / one at a time / selection) map to our **Pacing Policy** lookahead. They could stay internal, or a "Selection" mode could play just one segment.
12. **Light editing, cheapest first:** (a) retake a segment; (b) insert a pause (Murf's 0.25–1.25 s presets; silence insertion needs no model); (c) regenerate a selected sentence (Studio and Descript regenerate selections); (d) Descript-style "delete text → delete audio" driven by word timings. Make (d) non-destructive, with Ignore/Restore, and crossfade the cuts. A waveform timeline has little precedent outside the full editors.
13. **Offline QA and LLM helpers.** Studio's export QA checks for "missing or additional words" and retakes up to twice. The app's on-device speech recognizer could flag dropped words in a segment and offer a retake. The local LLM can do "Expand description" (Hume and ElevenLabs enhance), "Write reference line", and "Rewrite for speech" for numbers, dates and URLs (WellSaid; ElevenLabs normalizes by default). Anything that touches the script should follow ElevenLabs' Enhance rule of never changing words, or the character offsets must be remapped.
14. **Language:** auto-detect by default with an override menu (ElevenLabs auto-detects; Apple's "Detect languages" does the same). Add a pronunciation/replacement list (Apple, WellSaid, ElevenLabs). If text is substituted before synthesis, map highlight offsets back to the original text.

**Patterns that don't fit (or only after proving the engine supports them)**
- Credit counters, free-regeneration counts and hover tooltips, paid export gates (ElevenLabs, Murf). With nothing to charge, regenerate should cost only time.
- A cloud voice marketplace: notice periods, live moderation, sharing, "Studio Quality" badges (ElevenLabs Library). Our voices are descriptions plus takes. The only share analogue is export/import of a few-KB Pinned Voice file, not a server link (OpenAI.fm's Share).
- A model picker with many cloud models (ElevenLabs). There is one local model, so show precision or readiness, not a model menu.
- Inline tag syntaxes (`[whispers]`, `<sigh>`, `<break>`) and fixed emotion enums (Cartesia). Only teach syntax the model is verified to honor; otherwise chips should write plain words into the description. Per-passage delivery direction that is separate from identity (Gemini `style`, Hume acting) is only worth building if the engine keeps the Reference Take's identity when the instruction changes. Test first.
- Batch "3 candidates at once" (ElevenLabs, Hume) as the default: it triples on-device compute. Sequential takes with streaming fit better.
- Multi-speaker screenplay and dialogue editors, video timelines, agents (Gemini, ElevenLabs Studio): out of scope unless a document can hold several pinned voices.
- Cloning and consent flows (Descript, Gemini replication, ElevenLabs IVC/PVC): VoiceDesign doesn't clone.
